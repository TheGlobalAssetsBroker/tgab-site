# TGAB Brand Assets

## Logo
The mark is a faceted compass rose — four gradient-lit points with TGAB set at the
cardinal positions in serif type, contained within a double ring. The green core node
(#2EEB7A) is the brand anchor and ties to the site's Signal Green.

Meaning: global navigation and precision (compass) + market direction (the elongated
north point) + the TGAB name built into the instrument itself.

### Files
- `tgab-lockup-dark.svg`  — primary lockup, dark backgrounds (website, decks)
- `tgab-lockup-light.svg` — primary lockup, light backgrounds (documents, invoices)
- `tgab-mark-dark.svg`    — mark only, dark backgrounds
- `tgab-mark-light.svg`   — mark only, light backgrounds
- `tgab-favicon.svg`      — simplified: letters dropped, star enlarged, for 16-64px use

### Rules
- Never stretch, recolour, or rotate the mark.
- Minimum size with letters: 48px. Below that use the favicon variant.
- Clear space: at least half the mark's width on all sides.
- The green core stays green. It is the one fixed colour in the mark.
